<h1 align="center">📝 Sistema de To-Do List</h1>

<p align="center">
  Um gerenciador de tarefas desenvolvido em Python para treinar organização de dados, categorização e atualização de status.
</p>

---

### 🚀 Sobre o Projeto
Este é o meu segundo projeto prático construído para o meu portfólio. O objetivo aqui foi evoluir a complexidade em relação ao projeto anterior, introduzindo a capacidade de não apenas registrar dados, mas também alterar o estado deles (de pendente para concluído).

### 🛠️ Funcionalidades
* **Adição de Tarefas:** Cadastro de novas atividades com nome e categoria.
* **Atualização de Status:** Função para buscar uma tarefa específica e marcá-la como concluída.
* **Listagem Visual:** Exibição de todas as tarefas com ícones indicativos de status (⏳ Pendente / ✅ Concluída).

### 💻 Tecnologias e Conceitos
* **Python:** Manipulação de listas e dicionários.
* **Lógica de Programação:** Uso de laços de repetição (`for`) e estruturas condicionais (`if/else`) para buscar e atualizar informações precisas.
